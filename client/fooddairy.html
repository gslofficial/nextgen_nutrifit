ABOUT NUTRILIFE

Nutrition information made simple.

NutriLife is a front-end educational food portal. The starter food values in this demo are organized around a 100 g reference so the calculator can scale them to the selected amount.

For a production version, connect the portal to USDA FoodData Central or import a properly licensed food-composition dataset. FoodData Central provides food search and food-detail API endpoints and its data are public domain (CC0 1.0). View FoodData Central ↗
